# Validação visual — escala e cores dos KPI’s

A tela foi verificada no preview em 1280×720 e 375×812.

No desktop, as três categorias ocupam melhor a largura disponível, os cards usam maior altura e padding, os títulos e valores estão mais legíveis e o espaço entre linhas foi ampliado de forma controlada. Os fundos coloridos de estado foram removidos; os cards ficaram neutros, usando bordas e cores de texto apenas para hierarquia.

No mobile, cada categoria passa para uma coluna, os dois períodos permanecem lado a lado dentro do card, não há corte horizontal e a tela pode ser rolada verticalmente para os indicadores restantes. Os modais e os dados reais continuam preservados.
